Convolutional Neural Networks (CNN)

PyTorch + Shape/Param Math ~25 min read Expect: Spatial size/params + CustomCNN/Siamese

Instead of connecting every pixel to every neuron, a CNN slides small \(F\times F\) filters across an image. That gives local connectivity and weight sharing—slashing parameters by orders of magnitude.

Remember just these 3 things
  1. Output size: \(\lfloor (W - F + 2P)/S \rfloor + 1\). With kernel 3, padding 1, stride 1 the size stays the same; MaxPool2d(2) halves it.
  2. Conv params: \((F \cdot F \cdot C_{\text{in}} + 1)\cdot K\). Pooling has 0 params.
  3. Model pattern: [Conv → ReLU → Pool] × n → Flatten → Linear. Linear input = channels × H × W after the last pool (e.g. 128*4*4).

1. Spatial Size & Parameter Formulas (Memorize Cold)

The 4 CNN Exam Equations

For input \(W_1 \times H_1 \times C_{\text{in}}\), filter size \(F\), stride \(S\), padding \(P\), and \(K\) filters:

\[W_2 = \left\lfloor \frac{W_1 - F + 2P}{S} \right\rfloor + 1, \qquad D_2 = K\]
  • Same spatial size (\(S=1\)): \(P = \frac{F - 1}{2}\) (so \(F=3 \implies P=1\); \(F=5 \implies P=2\)).
  • Conv2d parameters (with bias): \(\text{Params} = (F \cdot F \cdot C_{\text{in}} + 1) \cdot K\).
  • Conv2d multiplications (FLOPs): \(W_2 \cdot H_2 \cdot K \cdot (F \cdot F \cdot C_{\text{in}})\).
  • Pooling (MaxPool2d, AvgPool2d): 0 learnable parameters! Depth \(D_2 = C_{\text{in}}\).
  • Siamese Contrastive Loss (Lab 10): \(L = y D^2 + (1-y)\max(0, m - D)^2\), where \(D = \|z_a - z_b\|_2\), \(y\in\{0,1\}\) (1 = same class).

2. PyTorch Models to Write on Paper (Lab 10)

Lab 10 · BasicCNN & CustomCNN (5-Class CIFAR-10 Assignment)
import torch
import torch.nn as nn
import torch.nn.functional as F

class BasicCNN(nn.Module):
    # Input: (B, 1, 32, 32)
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 8, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # -> 8x16x16
            nn.Conv2d(8, 16, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # -> 16x8x8
        )
        self.classifier = nn.Linear(16 * 8 * 8, num_classes)

    def forward(self, x):
        return self.classifier(self.features(x).flatten(1))

class CustomCNN(nn.Module):
    # Input: (B, 3, 32, 32) -> 5 classes (402,341 params)
    def __init__(self, num_classes=5):
        super().__init__()
        self.block1 = nn.Sequential(
            nn.Conv2d(3, 32, 3, stride=1, padding=1), nn.ReLU(),
            nn.Conv2d(32, 32, 3, stride=1, padding=1), nn.ReLU(),
            nn.MaxPool2d(2, stride=2),      # -> 32 x 16 x 16
        )
        self.block2 = nn.Sequential(
            nn.Conv2d(32, 64, 3, stride=1, padding=1), nn.ReLU(),
            nn.Conv2d(64, 64, 3, stride=1, padding=1), nn.ReLU(),
            nn.MaxPool2d(2, stride=2),      # -> 64 x 8 x 8
        )
        self.block3 = nn.Sequential(
            nn.Conv2d(64, 128, 3, stride=1, padding=1), nn.ReLU(),
            nn.MaxPool2d(2, stride=2),      # -> 128 x 4 x 4
        )
        self.head = nn.Sequential(
            nn.Flatten(),
            nn.Linear(128 * 4 * 4, 128), nn.ReLU(),
            nn.Dropout(0.4),
            nn.Linear(128, num_classes),
        )

    def forward(self, x):
        return self.head(self.block3(self.block2(self.block1(x))))
Lab 10 · LeNet5 & SiameseNetwork with Contrastive Loss
class LeNet5(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 6, 5)      # 32 -> 28
        self.pool = nn.AvgPool2d(2)          # 28 -> 14; 10 -> 5
        self.conv2 = nn.Conv2d(6, 16, 5)     # 14 -> 10
        self.conv3 = nn.Conv2d(16, 120, 5)   # 5 -> 1
        self.fc1 = nn.Linear(120, 84)
        self.fc2 = nn.Linear(84, num_classes)

    def embedding(self, x):
        x = self.pool(torch.tanh(self.conv1(x)))
        x = self.pool(torch.tanh(self.conv2(x)))
        x = torch.tanh(self.conv3(x)).flatten(1)
        return torch.tanh(self.fc1(x))

    def forward(self, x):
        return self.fc2(self.embedding(x))

class SiameseNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.encoder = LeNet5(num_classes=10)
        self.encoder.fc2 = nn.Identity()

    def forward(self, a, b):
        za = F.normalize(self.encoder.embedding(a), dim=1)
        zb = F.normalize(self.encoder.embedding(b), dim=1)
        return za, zb

def pair_distance(za, zb):
    return torch.norm(za - zb, dim=1)

def contrastive_loss(za, zb, same, margin=1.0):
    d = pair_distance(za, zb)
    return (same * d.square() + (1 - same) * F.relu(margin - d).square()).mean()

3. Key Ideas Worth One Line Each

  • LeNet-5 (Lab 10): 5×5 convs + AvgPool(2) + tanh. Shapes: 32→28→14→10→5→1, and conv3 maps 16×5×5 → 120×1×1.
  • Siamese (Lab 10): the same encoder (shared weights) embeds both images; similar pairs pulled together, different pairs pushed at least margin \(m\) apart.
  • Two 3×3 convs vs one 5×5: same 5×5 view of the image, fewer weights (\(18C^2\) vs \(25C^2\)) and one extra ReLU.
  • 1×1 conv: mixes/shrinks channels cheaply (see the box below).
  • Why Dropout(0.4) in CustomCNN: randomly zeroes neurons during training to reduce overfitting; turned off by model.eval().

4. Hand Convolution + Param Check + Practice

Hand 2D Cross-Correlation (CNN.pdf Q12)

Input \(I = \begin{bmatrix}1&2&0&1\\0&1&3&2\\2&1&0&1\\1&0&2&3\end{bmatrix}\), Filter \(K = \begin{bmatrix}1&0&-1\\1&0&-1\\1&0&-1\end{bmatrix}\), \(S=1, P=0\):

  1. Output size: \((4 - 3 + 0)/1 + 1 = 2 \times 2\).
  2. Top-left: \((1+0+2) - (0+3+0) = 0\). Top-right: \((2+1+1) - (1+2+1) = 0\).
  3. Bottom-left: \((0+2+1) - (3+0+2) = -2\). Bottom-right: \((1+1+0) - (2+1+3) = -4\).
  4. Result: \(\begin{bmatrix}0 & 0\\-2 & -4\end{bmatrix}\). This filter detects vertical edges (left minus right). Same-size padding: \(P=(3-1)/2=1\).
Why 1×1 Convs Save Work (worked numbers)

On a 28×28×192 input, a direct 5×5 conv with 32 filters has (25×192+1)×32 = 153,632 params and ~120.4M multiplications. Putting a 1×1 conv with 16 filters first drops this to 15,920 params and ~12.4M multiplications (~9.7× less work).
