K-Nearest Neighbours (KNN)

Scratch NumPy + sklearn ~20 min read Expect: Distance/vote code + scaling why + trace

KNN fits no equation during training. It memorizes the training data; for any new query, it measures distances, grabs the K closest training points, and predicts the majority class.

1. Plain Intuition

Non-parametric & Lazy Learner

Training cost: zero (just store X_train, y_train). Test cost: \(O(n_{\text{train}}\cdot d)\) per query because you compute distance to every stored training sample.

Because it uses raw distances, feature scaling is mandatory: if Feature A is in \([1000, 50000]\) and Feature B is in \([0.1, 0.9]\), Feature A completely hijacks the distance!

2. Core Formulas

Distance, Majority Rule, Scaling & Dimensionality
  • Euclidean Distance: \(d(x, z) = \sqrt{\sum_{j=1}^d (x_j - z_j)^2}\)
  • Manhattan Distance: \(d_1(x, z) = \sum_{j=1}^d |x_j - z_j|\)
  • KNN Probability & Prediction: \(\hat{P}(Y=c\mid X=x) = \frac{1}{K}\sum_{i\in N_K(x)} \mathbf{1}(y_i = c), \quad \hat{y} = \arg\max_c \sum_{i\in N_K(x)} \mathbf{1}(y_i = c)\)
  • Standardization: \(z_j = \frac{x_j - \mu_j}{\sigma_j}\) (computed on training fold ONLY!)
  • Curse of Dimensionality: Hypercube edge needed to capture fraction \(r\) of points in \(p\) dims is \(l_p(r) = r^{1/p}\) (e.g., \(p=10, r=0.1 \implies 0.1^{0.1} \approx 0.794\), so nearest neighbors stop being local).

3. Pen-and-Paper Code (Lab 6)

Lab 6 · KNN from Scratch (NumPy)
import numpy as np

def euclidean_distances(X_train, x_query):
    return np.sqrt(np.sum((X_train - x_query) ** 2, axis=1))

def get_nearest_indices(distances, k):
    return np.argsort(distances)[:k]

def majority_vote(labels):
    classes, counts = np.unique(labels, return_counts=True)
    return classes[np.argmax(counts)]

def knn_predict_one(X_train, y_train, x_query, k):
    distances = euclidean_distances(X_train, x_query)
    nearest_idx = get_nearest_indices(distances, k)
    nearest_labels = y_train[nearest_idx]
    return majority_vote(nearest_labels)

def knn_predict(X_train, y_train, X_query, k):
    return np.array([knn_predict_one(X_train, y_train, x, k) for x in X_query])
Lab 6 · sklearn Leakage-Free Pipeline + GridSearchCV
from sklearn.model_selection import StratifiedKFold, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.neighbors import KNeighborsClassifier

knn_pipeline = Pipeline([
    ("scaler", StandardScaler()),
    ("knn", KNeighborsClassifier()),
])

knn_param_grid = {
    "knn__n_neighbors": list(range(1, 32, 2)),  # odd K prevents binary ties
    "knn__weights": ["uniform", "distance"],
    "knn__metric": ["euclidean", "manhattan"],
}

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
knn_grid = GridSearchCV(knn_pipeline, knn_param_grid, cv=cv, scoring="accuracy")
knn_grid.fit(X_train, y_train)
test_acc = knn_grid.score(X_test, y_test)
Classic Exam Trap: Data Leakage

Never run scaler.fit_transform(X_train) before cross-validation! Put StandardScaler() inside Pipeline so each CV fold computes \(\mu_j, \sigma_j\) strictly from its training split.

4. Worked Hand-Trace (Lab 6 Toy Points) + Practice

Exact Lab 6 Manual Example

Training points: \(A=(1,1)\to 0,\; B=(2,1)\to 0,\; C=(4,3)\to 1,\; D=(5,4)\to 1\). Query \(x_q=(3,2)\), \(K=3\):

  1. \(d(x_q, A) = \sqrt{(3-1)^2+(2-1)^2} = \sqrt{5} \approx 2.2361\)
  2. \(d(x_q, B) = \sqrt{(3-2)^2+(2-1)^2} = \sqrt{2} \approx 1.4142\)
  3. \(d(x_q, C) = \sqrt{(3-4)^2+(2-3)^2} = \sqrt{2} \approx 1.4142\)
  4. \(d(x_q, D) = \sqrt{(3-5)^2+(2-4)^2} = \sqrt{8} \approx 2.8284\)
  5. Nearest 3: \([B(0),\; C(1),\; A(0)] \implies\) counts `{0: 2, 1: 1}` → Predict 0.

5. Quick Exam Self-Checks

Check 1How does changing K affect bias, variance, and decision boundary? (Flexibility = 1/K)
  • Small K (e.g., K=1): High flexibility, low bias, high variance (jagged boundary, sensitive to noise, 0 training error on distinct points).
  • Large K (e.g., K=25 or n): Low flexibility, high bias, low variance (smooth boundary; at \(K=n\), predicts overall majority class everywhere).
Check 2What happened in Lab 6 Breast Cancer when scaling was removed?

5-fold CV accuracy dropped from 0.972 (with StandardScaler in Pipeline) to 0.946 (unscaled) because features like area (~1000) drowned out features like smoothness (~0.1).
