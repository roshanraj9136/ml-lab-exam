Topic 6 · Lab 11 (Manual RNN, LSTM, GRU)

RNN and Variants

Manual PyTorch Gates (No nn.LSTM) ~30 min read Expect: Cell code + scalar/param math + BPTT bugs

In Lab 11, you built RNN, LSTM, and GRU cells manually using nn.Linear gates and unrolled loops—not PyTorch's built-in nn.RNN/LSTM/GRU. Know the 3 cells, parameter counts, vanishing-gradient fix, and T-BPTT.

Remember just these 3 things
  1. RNN: \(h_t = \tanh(W_x x_t + W_h h_{t-1} + b)\), same weights reused at every time step (loop over t).
  2. LSTM: 4 gates (forget, input, candidate, output). \(c_t = f\cdot c_{t-1} + i\cdot g\), \(h_t = o\cdot\tanh(c_t)\). The additive \(c_t\) path stops gradients vanishing. GRU: 3 gates, \(h_t = (1-z)n + z\,h_{t-1}\).
  3. Params: RNN \(h(d+h+1)\), GRU \(3\times\), LSTM \(4\times\). Clip gradients (clip_grad_norm_) for exploding; .detach() the state between chunks for T-BPTT.

1. RNN vs LSTM vs GRU Equations

Update Rules at Time Step \(t\)
  • Vanilla RNN: \(h_t = \tanh(W_x x_t + W_h h_{t-1} + b)\)
  • LSTM (state = \((h_t, c_t)\)): \[f_t = \sigma(W_f[x_t, h_{t-1}] + b_f), \quad i_t = \sigma(W_i[x_t, h_{t-1}] + b_i), \quad g_t = \tanh(W_g[x_t, h_{t-1}] + b_g)\] \[c_t = f_t \odot c_{t-1} + i_t \odot g_t, \qquad o_t = \sigma(W_o[x_t, h_{t-1}] + b_o), \qquad h_t = o_t \odot \tanh(c_t)\]
  • GRU (PyTorch / Lab 11 reset-before-linear convention): \[r_t = \sigma(W_{ir}x_t + W_{hr}h_{t-1} + b_r), \quad z_t = \sigma(W_{iz}x_t + W_{hz}h_{t-1} + b_z)\] \[n_t = \tanh(W_{in}x_t + r_t \odot (W_{hn}h_{t-1} + b_{hn}) + b_{in}), \qquad h_t = (1 - z_t)\odot n_t + z_t\odot h_{t-1}\]

Why gates use \(\sigma\) and candidates use \(\tanh\)? Gates act as smooth \(0..1\) valves (forget/keep/expose); candidates & hidden states need \((-1, 1)\) range so values can add or subtract.

2. Pen-and-Paper Code (Lab 11 Manual Cells & Training)

Lab 11 · ManualRNNCell, ManualLSTMCell & ManualGRUCell
import torch
import torch.nn as nn

class ManualRNNCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.input_to_hidden = nn.Linear(input_size, hidden_size)
        self.hidden_to_hidden = nn.Linear(hidden_size, hidden_size, bias=False)

    def forward(self, x_t, h_prev):
        return torch.tanh(self.input_to_hidden(x_t) + self.hidden_to_hidden(h_prev))

class ManualLSTMCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        combined = input_size + hidden_size
        self.forget_gate = nn.Linear(combined, hidden_size)
        self.input_gate = nn.Linear(combined, hidden_size)
        self.candidate_gate = nn.Linear(combined, hidden_size)
        self.output_gate = nn.Linear(combined, hidden_size)

    def forward(self, x_t, state):
        h_prev, c_prev = state
        combined = torch.cat((x_t, h_prev), dim=-1)
        f_t = torch.sigmoid(self.forget_gate(combined))
        i_t = torch.sigmoid(self.input_gate(combined))
        g_t = torch.tanh(self.candidate_gate(combined))
        c_t = f_t * c_prev + i_t * g_t
        o_t = torch.sigmoid(self.output_gate(combined))
        h_t = o_t * torch.tanh(c_t)
        return (h_t, c_t)

class ManualGRUCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.W_ir = nn.Linear(input_size, hidden_size)
        self.W_hr = nn.Linear(hidden_size, hidden_size)
        self.W_iz = nn.Linear(input_size, hidden_size)
        self.W_hz = nn.Linear(hidden_size, hidden_size)
        self.W_in = nn.Linear(input_size, hidden_size)
        self.W_hn = nn.Linear(hidden_size, hidden_size)

    def forward(self, x_t, h_prev):
        r_t = torch.sigmoid(self.W_ir(x_t) + self.W_hr(h_prev))
        z_t = torch.sigmoid(self.W_iz(x_t) + self.W_hz(h_prev))
        n_t = torch.tanh(self.W_in(x_t) + r_t * self.W_hn(h_prev))
        return (1 - z_t) * n_t + z_t * h_prev
Lab 11 · Unrolled Wrapper, Next-Token Model & Training Loop (with T-BPTT & Clipping)
class ManualRecurrent(nn.Module):
    def __init__(self, kind, input_size, hidden_size):
        super().__init__()
        self.kind = kind.upper()
        self.hidden_size = hidden_size
        cells = {"RNN": ManualRNNCell, "LSTM": ManualLSTMCell, "GRU": ManualGRUCell}
        self.cell = cells[self.kind](input_size, hidden_size)

    def forward(self, embeddings, state=None):
        B, T, _ = embeddings.shape
        if state is None:
            h = embeddings.new_zeros(B, self.hidden_size)
            c = embeddings.new_zeros(B, self.hidden_size) if self.kind == "LSTM" else None
        else:
            h, c = state if self.kind == "LSTM" else (state, None)
        outputs = []
        for t in range(T):
            x_t = embeddings[:, t, :]
            if self.kind == "LSTM":
                h, c = self.cell(x_t, (h, c))
            else:
                h = self.cell(x_t, h)
            outputs.append(h)
        final_state = (h, c) if self.kind == "LSTM" else h
        return torch.stack(outputs, dim=1), final_state

class ManualNextTokenModel(nn.Module):
    def __init__(self, kind, vocab_size, embedding_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.recurrent = ManualRecurrent(kind, embedding_dim, hidden_dim)
        self.output_layer = nn.Linear(hidden_dim, vocab_size)

    def forward(self, token_ids):
        outputs, _ = self.recurrent(self.embedding(token_ids))
        return self.output_layer(outputs)  # shape: (B, T, V)

criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.003)
for x, y in train_loader:

3. Parameter Counting & Vanishing Gradient Fix

Refute the Myth (LSTM-GRU.pdf Q7): How Does LSTM Fix Vanishing Gradients?

FALSE: "Because \(\sigma'(z) \approx 1\)." (Wrong—\(\max \sigma'(z) = 0.25\)!)

TRUE (Constant Error Carousel): \(c_t = f_t \odot c_{t-1} + i_t \odot g_t\), so the direct path is \(\frac{\partial c_t}{\partial c_{t-1}} = f_t \implies \frac{\partial c_T}{\partial c_k} = \prod_{t=k+1}^T f_t\). There is no \(\tanh\) or \(W_h\) multiplication on the cell highway, so when \(f_t \approx 1\), gradients survive long horizons! (Gradient clipping fixes exploding gradients, not vanishing ones.)

4. Scalar Traces + Bug Drills + Practice

Quick Scalar Traces (RNN, LSTM, GRU)
  • Scalar RNN: \(h_0=0, w_h=0.5, w_x=1, x=(1,0,-1) \implies h_1=\tanh(1)=0.7616,\; h_2=\tanh(0.3808)=0.3634,\; h_3=\tanh(0.1817-1)=-0.6741\).
  • Scalar LSTM: \(c_{t-1}=0.8, f_t=0.9, i_t=0.2, g_t=-0.5, o_t=0.75 \implies c_t = 0.9(0.8)+0.2(-0.5) = \mathbf{0.6200},\; h_t = 0.75\tanh(0.62) = \mathbf{0.4133}\). After 20 steps: \(\partial c_{20}/\partial c_0 = 0.9^{20} = \mathbf{0.1216}\).
  • Scalar GRU: \(h_{t-1}=0.6, z_t=0.75, r_t=0.5, x_t=1, w_x=0.4, w_h=1 \implies n_t = \tanh(0.4 + 0.5\times 0.6) = 0.6044,\; h_t = 0.25(0.6044) + 0.75(0.6) = \mathbf{0.6011}\). Direct \(\partial h_t/\partial h_{t-1} = z_t = 0.75\). If \(z_t \to 1\): keeps \(h_{t-1}\); if \(z_t \to 0\): overwrites with \(n_t\).
2 Must-Know Bug Hunts

1. BPTT Pseudocode (3 bugs):

for t = T down to 1:
    delta_t = (d l_t / d h_t) * tanh'(a_t)  # BUG 1: ignores future gradient + W_h^T @ delta_{t+1}!
    grad_W_h = delta_t * h_{t-1}^T         # BUG 2: overwrites instead of accumulating (+=)!
    W_h = W_h - eta * grad_W_h             # BUG 3: updates shared W_h inside loop! (Clip + update AFTER loop)

2. Buggy LSTM (2 bugs):

c_t = tanh(f_t * c_{t-1} + i_t * g_t) and h_t = o_t * c_t: (1) wrapping c_t in tanh kills the linear cell-state highway (causes vanishing gradients); (2) dropping tanh in h_t = o_t * tanh(c_t) lets h_t grow unbounded.

5. One More Variant: Bidirectional RNN

  • Bidirectional RNN: runs one RNN forward and one backward, then concatenates \(h_t^\rightarrow\) and \(h_t^\leftarrow\). Good when the whole sentence is available (sentiment, NER). Not usable for next-token prediction (like Lab 11) or live speech, because it needs future inputs \(x_{t+1..T}\).
