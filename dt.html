Decision Tree

Scratch NumPy ~20 min read Expect: Gini/Entropy code + hand split

A decision tree splits data step-by-step using threshold questions like petal_width <= 1.75 so that each child group becomes as pure (single-class) as possible.

Remember just these 3 things
  1. Gini = 1 − Σp² and Entropy = −Σp·log₂p. Pure = 0, 50/50 = 0.5 / 1.0.
  2. Thresholds = midpoints of sorted unique values. Pick the split with the lowest weighted impurity.
  3. Stop when the node is pure, too small, too deep, or no valid split exists → leaf = majority class.

1. Plain Intuition

How the algorithm thinks

At any node, we want to pick one feature and one threshold that splits the points into Left (x[:, j] <= t) and Right (> t) with the lowest combined impurity.

To find candidate thresholds on a continuous feature, Lab 7 sorts unique values and checks every midpoint between adjacent values. Once split, it calls itself recursively on Left and Right until a stopping rule hits.

2. Formulas You Must Know

Impurity, Split Cost & Information Gain

Let \(p_c = \frac{\sum_{j: y_j = c} w_j}{\sum_j w_j}\) be the (weighted) fraction of class \(c\):

\[\text{Gini}(S) = 1 - \sum_{c=1}^{C} p_c^2 \qquad\qquad H(S) = -\sum_{c=1}^{C} p_c \log_2(p_c)\] \[\text{Weighted Split Impurity} = \frac{W_L}{W}\,\text{Imp}(L) + \frac{W_R}{W}\,\text{Imp}(R)\] \[\text{Information Gain} = H(\text{parent}) - \left(\frac{W_L}{W}H(L) + \frac{W_R}{W}H(R)\right)\]
  • Pure node (all same class): \(\text{Gini} = 0,\; H = 0\).
  • 50/50 binary split: \(\text{Gini} = 0.5,\; H = 1.0\).
Why Gini and Entropy Usually Pick the Same Split (Lab 7 Task 1.6)

Both curves have the same shape: 0 for a pure node, maximum at 50/50 (Gini = 0.5, Entropy = 1.0), so Entropy is roughly \(2\times\) Gini. Because they rise and fall together, they usually pick the same best split. Gini is slightly faster because it needs no \(\log_2\). (In Lab 7, DT and RF gave the same 0.80 test accuracy with either criterion.)

Lab 7 · Impurity & Best Split Helpers
import numpy as np

def gini(y, weights=None):
    y = np.asarray(y)
    weights = np.ones(len(y), dtype=float) if weights is None else np.asarray(weights, dtype=float)
    total = weights.sum()
    if total == 0:
        return 0.0
    impurity = 1.0
    for c in np.unique(y):
        p = weights[y == c].sum() / total
        impurity -= p ** 2
    return impurity

def entropy(y, weights=None):
    y = np.asarray(y)
    weights = np.ones(len(y), dtype=float) if weights is None else np.asarray(weights, dtype=float)
    total = weights.sum()
    if total == 0:
        return 0.0
    ent = 0.0
    for c in np.unique(y):
        p = weights[y == c].sum() / total
        if p > 0:
            ent -= p * np.log2(p)
    return ent

def candidate_thresholds(X, feature):
    values = np.sort(np.unique(X[:, feature]))
    if len(values) < 2:
        return np.array([])
    return (values[:-1] + values[1:]) / 2

def make_split_masks(X, feature, threshold):
    left = X[:, feature] <= threshold
    return left, ~left

def weighted_split_impurity(y, weights, left, right, criterion="gini"):
    total = weights.sum()
    wl, wr = weights[left], weights[right]
    fn = entropy if criterion == "entropy" else gini
    l_imp, r_imp = fn(y[left], wl), fn(y[right], wr)
    return (wl.sum() / total) * l_imp + (wr.sum() / total) * r_imp, l_imp, r_imp

def best_split(X, y, weights=None, features=None, criterion="gini"):
    n_samples, n_features = X.shape
    if weights is None: weights = np.ones(n_samples, dtype=float)
    if features is None: features = np.arange(n_features)
    best_imp, best_feat, best_thresh = np.inf, None, None
    for f in features:
        for t in candidate_thresholds(X, f):
            left, right = make_split_masks(X, f, t)
            if not left.any() or not right.any():
                continue
            w_imp, _, _ = weighted_split_impurity(y, weights, left, right, criterion)
            if w_imp < best_imp:
                best_imp, best_feat, best_thresh = w_imp, f, t
    return best_feat, best_thresh
Lab 7 · Node & DecisionTreeScratch
class Node:
    def __init__(self, feature=None, threshold=None, left=None, right=None, value=None):
        self.feature = feature
        self.threshold = threshold
        self.left = left
        self.right = right
        self.value = value

    def is_leaf(self):
        return self.value is not None

class DecisionTreeScratch:
    def __init__(self, max_depth=5, min_samples_split=2, max_features=None,
                 criterion="gini", random_state=42):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.max_features = max_features
        self.criterion = criterion
        self.rng = np.random.default_rng(random_state)
        self.root = None

    def _majority(self, y, weights):
        classes = np.unique(y)
        scores = [weights[y == c].sum() for c in classes]
        return classes[np.argmax(scores)]

    def _features(self, n_features):
        if self.max_features is None:
            return np.arange(n_features)
        if self.max_features == "sqrt":
            k = max(1, int(np.sqrt(n_features)))
        elif self.max_features == "log2":
            k = max(1, int(np.log2(n_features)))
        else:
            k = int(self.max_features)
        return self.rng.choice(n_features, size=min(k, n_features), replace=False)

    def _grow(self, X, y, weights, depth):
        if len(np.unique(y)) == 1 or len(y) < self.min_samples_split or depth >= self.max_depth:
            return Node(value=self._majority(y, weights))
        features = self._features(X.shape[1])
        feature, threshold = best_split(X, y, weights, features, self.criterion)
        if feature is None:
            return Node(value=self._majority(y, weights))
        left_m, right_m = make_split_masks(X, feature, threshold)
        left = self._grow(X[left_m], y[left_m], weights[left_m], depth + 1)
        right = self._grow(X[right_m], y[right_m], weights[right_m], depth + 1)
        return Node(feature=feature, threshold=threshold, left=left, right=right)

    def fit(self, X, y, sample_weight=None):
        X, y = np.asarray(X), np.asarray(y)
        w = np.ones(len(y), dtype=float) if sample_weight is None else np.asarray(sample_weight, dtype=float)
        self.root = self._grow(X, y, w, 0)
        return self

    def _predict_one(self, x, node):
        if node.is_leaf():
            return node.value
        return self._predict_one(x, node.left) if x[node.feature] <= node.threshold else self._predict_one(x, node.right)

    def predict(self, X):
        return np.array([self._predict_one(x, self.root) for x in np.asarray(X)])

4. Worked Hand-Trace + Practice

Step-by-Step Numerical Example

Suppose feature \(x = [1.0, 2.0, 3.0, 4.0]\) has labels \(y = [0, 0, 1, 1]\):

  1. Candidate thresholds (midpoints): \((1+2)/2 = 1.5\), \((2+3)/2 = 2.5\), \((3+4)/2 = 3.5\).
  2. Try \(t = 1.5\): Left \(=[0]\) (Gini \(=0\)), Right \(=[0,1,1]\) (Gini \(= 1 - (1/3)^2 - (2/3)^2 = 4/9 = 0.444\)). Weighted Gini \(= \frac{1}{4}(0) + \frac{3}{4}(0.444) = \mathbf{0.333}\).
  3. Try \(t = 2.5\): Left \(=[0,0]\) (Gini \(=0\)), Right \(=[1,1]\) (Gini \(=0\)). Weighted Gini \(= \mathbf{0.0}\) → Best split!

5. Quick Exam Self-Checks

Check 1What are the 4 stopping conditions in DecisionTreeScratch._grow?
  1. Node is pure: len(np.unique(y)) == 1
  2. Too few samples to split: len(y) < self.min_samples_split
  3. Reached max depth: depth >= self.max_depth
  4. No valid split found (all features identical at node): feature is None
Check 2Why does entropy() check if p > 0?

To avoid 0 * log2(0) = nan. By convention \(0\log_2 0 = 0\), so empty classes are simply skipped.

Check 3Why does a fully grown tree overfit, and which parameters stop it?

Grown until every leaf is pure, the tree memorises noise (high variance). In Lab 7 we limit it with max_depth and min_samples_split.
