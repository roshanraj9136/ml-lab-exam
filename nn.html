1. Activations, Losses & Formulas

ActivationFormula \(g(z)\)Derivative \(g'(z)\)Key Lab Note
Sigmoid\(\frac{1}{1+e^{-z}}\)\(\sigma(z)(1-\sigma(z)) \le \frac{1}{4}\)Non-zero-centered; vanishes in deep nets (`5e-7` at 8 layers)
Tanh\(2\sigma(2z)-1\)\(1-\tanh^2(z) \le 1\)Zero-centered; still saturates at large \(|z|\)
ReLU\(\max(0, z)\)\(1\text{ if }z>0\text{ else }0\)Fast, no saturation for \(z>0\), can suffer dead units
Leaky ReLU\(\max(\alpha z, z)\)\(1\text{ if }z>0\text{ else }\alpha\)Lab 9 Ext 3 (`alpha=0.01`): fixes dead ReLUs
Swish\(z\,\sigma(\beta z)\)\(\sigma(\beta z) + \beta z\sigma(\beta z)(1-\sigma(\beta z))\)\(\beta\to\infty \implies \text{ReLU}\); \(\beta\to 0 \implies z/2\)
Softmax\(\frac{e^{a_k - m}}{\sum_j e^{a_j - m}}\)Used with Cross-EntropySubtract \(m=\max(a)\) to prevent overflow!
Why BCEWithLogitsLoss & CrossEntropyLoss Cancel Saturation
  • Binary (Sigmoid + BCE): \(L = -[y\ln a + (1-y)\ln(1-a)] \implies \frac{\partial L}{\partial z} = a - y\) (clean! No \(\sigma'(z)\) vanishing factor).
  • Multi-class (Softmax + CE, true class \(l\)): \(L = -\ln \hat{y}_l \implies \frac{\partial L}{\partial a_L} = \hat{y} - e^{(l)}\).
  • General Backprop Recurrences: \(\delta_i = \frac{\partial L}{\partial a_i} = (W_{i+1}^T \delta_{i+1}) \odot g'(a_i)\), \(\quad \frac{\partial L}{\partial W_i} = \delta_i h_{i-1}^T\), \(\quad \frac{\partial L}{\partial b_i} = \delta_i\).
  • He Init for ReLU: \(\text{Var}(W) = \frac{2}{n_{\text{in}}}\) (for LeakyReLU(\(\alpha\)): \(\frac{2}{n_{\text{in}}(1+\alpha^2)}\)).

2. Manual NumPy Forward, Backprop & Optimizers (Lab 8)

Lab 8 · Forward, 3-Layer Backprop (ReLU → ReLU → Sigmoid/BCE), RMSprop & Adam
def sigmoid(z): return 1.0 / (1.0 + np.exp(-z))
def relu(z): return np.maximum(0, z)

def forward(x, Ws, bs, acts):
    out = [x]
    for W, b_, f in zip(Ws, bs, acts):
        out.append(f(W @ out[-1] + b_))
    return out

# Forward pass saving z and a:
z1 = Ws[0] @ x_B + bs[0];  a1 = relu(z1)
z2 = Ws[1] @ a1  + bs[1];  a2 = relu(z2)
z3 = Ws[2] @ a2  + bs[2];  a3 = sigmoid(z3)

# Backward pass:
dL_da3  = -(y_B / a3) + (1 - y_B) / (1 - a3)
da3_dz3 = a3 * (1 - a3)
delta3  = dL_da3 * da3_dz3                     # equals (a3 - y_B)
dW3 = np.outer(delta3, a2);  db3 = delta3

delta2 = np.where(z2 > 0, Ws[2].T @ delta3, 0.0)
dW2 = np.outer(delta2, a1);  db2 = delta2

delta1 = np.where(z1 > 0, Ws[1].T @ delta2, 0.0)
dW1 = np.outer(delta1, x_B); db1 = delta1

def rmsprop_step(params, grads, v, lr=0.01, rho=0.9, eps=1e-8):
    new = []
    for l in range(len(params)):
        v[l] = rho * v[l] + (1 - rho) * grads[l] ** 2
        new.append(params[l] - lr * grads[l] / (np.sqrt(v[l]) + eps))
    return new

def adam_step(params, grads, m, v, t, lr=0.01, b1=0.9, b2=0.999, eps=1e-8):
    new = []
    for l in range(len(params)):
        m[l] = b1 * m[l] + (1 - b1) * grads[l]
        v[l] = b2 * v[l] + (1 - b2) * grads[l] ** 2
        m_hat = m[l] / (1 - b1 ** t)
        v_hat = v[l] / (1 - b2 ** t)
        new.append(params[l] - lr * m_hat / (np.sqrt(v_hat) + eps))
    return new

3. PyTorch DNN / MoonANN & Training Loop (Labs 8 & 9)

Labs 8–9 · PyTorch nn.Module + BCEWithLogitsLoss Training Loop
import torch
import torch.nn as nn

class DNN(nn.Module):
    def __init__(self, n_inputs, hidden):
        super().__init__()
        layers, prev = [], n_inputs
        for h in hidden:
            layers += [nn.Linear(prev, h), nn.ReLU()]
            prev = h
        layers.append(nn.Linear(prev, 1))   # raw logit, NO sigmoid here!
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        return self.net(x).squeeze(1)

model = DNN(n_inputs=30, hidden=[64, 32])
loss_fn = nn.BCEWithLogitsLoss()            # combines Sigmoid + BCE stably
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(epochs):
    model.train()
    for xb, yb in train_loader:
        optimizer.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward()
        optimizer.step()

model.eval()
with torch.no_grad():
    preds = (torch.sigmoid(model(X_test_t)) >= 0.5).int()

4. Optimizers & Depth Takeaways (Lab 9)

  • Anisotropic Bowl \(L(x,y) = 0.5(3x^2+y^2)\): Max curvature \(\lambda_{\max}=3\), so GD diverges if \(\eta \ge 2/\lambda_{\max} = 2/3\).
  • Momentum (\(\beta=0.9\)): Effective step along flat directions multiplies by \(\frac{1}{1-\beta} = 10\times\) (so Momentum at `lr=0.001` behaves like SGD at `lr=0.01`).
  • Overfitting vs Depth (Lab 8): Deeper MLPs (`[128,64,32]`) overfit tiny tabular data earliest (val loss rose after epoch 11); a simple `LogisticRegression` even beat deep MLPs on Breast Cancer (`98.25%` vs `96.49%`).
  • 8-Layer Sigmoid vs Adam (Lab 9 Ext 5): Deep sigmoid nets crush gradients (`5e-7` at layer 1) so SGD/Momentum stall, whereas Adam rescales tiny gradients via \(\hat{m}/\sqrt{\hat{v}}\) and still trains.

2–2–2 Sigmoid + Softmax Hand-Trace (Question Bank Q36)

\(W_1 = \begin{bmatrix}0.5 & -0.5\\1 & 0.5\end{bmatrix},\; W_2 = \begin{bmatrix}1 & 2\\-1 & 1\end{bmatrix},\; b=0,\; x=(1,-1)^T,\; \text{true class } l=1\):

  1. Forward: \(a_1 = W_1 x = [1.0, 0.5]^T \implies h_1 = [\sigma(1), \sigma(0.5)]^T = [0.7311, 0.6225]^T\).
  2. \(a_2 = W_2 h_1 = [1.9760, -0.1086]^T \implies \hat{y} = \text{softmax}(a_2) = [0.8894, 0.1106]^T\). Loss \(L = -\ln(0.8894) = 0.1172\).
  3. Backward: \(\nabla_{a_2}L = \hat{y} - [1,0]^T = [-0.1106, 0.1106]^T\).
  4. \(\nabla_{h_1}L = W_2^T \nabla_{a_2}L = [-0.2212, -0.1106]^T\).
  5. \(\nabla_{a_1}L = \nabla_{h_1}L \odot h_1(1-h_1) = [-0.0435, -0.0260]^T \implies \nabla_{W_1}L = \nabla_{a_1}L\, x^T = \begin{bmatrix}-0.0435 & 0.0435\\-0.0260 & 0.0260\end{bmatrix}\).
