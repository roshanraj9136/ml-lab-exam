# DSL501 Lab Exam Prep

Focused, concise revision site for the **DSL501: ML** offline pen-and-paper lab exam, covering strictly the 6 announced lab topics (Labs 6–11):

1. Decision Tree (Lab 7)
2. Random Forest (Lab 7)
3. KNN (Lab 6)
4. Neural Networks (Labs 8–9)
5. CNN (Lab 10)
6. RNN & Variants (Lab 11)

## Build Locally

```bash
python build.py
```

Open `index.html` or serve the directory with `python -m http.server`.
